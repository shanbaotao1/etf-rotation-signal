# ETF 动量轮动 · 云端信号备份

这是本地策略 `etf_rotation_1.py`（单只满仓 + 熊市切避险池 + 动态动量窗口 + 防御ETF兜底）的**云端镜像**。

当本地极空间 / PanWatch 挂掉时，你仍然可以在 GitHub 网页上查看每日 13:30（北京时间）的买卖信号，作为备用查看。

## 怎么看信号
- 打开仓库里的 **`SIGNAL.md`**（GitHub 会渲染成漂亮页面），或 **`index.html`**（手机友好）。
- 内容：今日操作建议（卖出/买入清单 + 建议股数）、市场状态、候选排名前 10、数据覆盖情况。

## 它是怎么跑的
- GitHub Actions 在每个交易日 **13:30 北京时间（UTC 05:30）** 自动运行工作流 `daily_signal.yml`。
- 数据源：**新浪实时/日K（主） + 东财（兜底）** —— 全部是公开接口，不依赖你的极空间。
- 跑完把 `SIGNAL.md` / `index.html` / `positions_v1.json` 提交回仓库，所以你随时刷新网页就能看到最新信号。
- 也可在 GitHub 网页 `Actions` 标签里手动 `Run workflow` 立即触发一次。

## 与本地脚本的区别
- 本地版用 PanWatch（内网 192.168.123.156）拿行情；云端版**跳过 PanWatch**，改用公开行情。
- 策略内核（打分、R²、regime、动态窗口、避险池、防御ETF）**完全一致**。
- 云端版是**单次计算 + 写报告**，不做分钟级循环、不做真实下单（实际买卖仍在你本地执行）。

## 重要说明
- 这是**备用信号**，不是自动交易。实际下单以你本地脚本/券商为准。
- GitHub 定时任务可能有几分钟延迟；若当天市场异常（停牌、数据源波动），信号仅供参考。
- 本仓库为**私有**，仅你自己可见。

## 维护
- 想改策略参数（如 `SINGLE_HOLDING`、`TOTAL_CAPITAL`、ETF 池），直接改 `etf_rotation_1.py` 后提交即可，下次运行生效。
- 想同步你真实的持仓，编辑 `positions_v1.json`（格式同本地）并提交；报告里的“卖出/买入”会基于它给出相对建议。
